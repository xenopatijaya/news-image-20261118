A newspaper front page summing up the world's news of Wednesday 18 November 2026: the APEC summit opens in Shenzhen with Xi Jinping chairing, Trump arrives late Wednesday after Quad talks in Manila, and a first three-way Xi–Trump–Putin meeting is set for Thursday. A labelled world map and a numbered grid carry 36 more stories from six continents — Kyiv, Gaza, the Gulf, Delhi, London, Sudan, Pakistan, and beyond — every one an event that happened or was first reported on 18 November 2026.

The image (`entry.png`, 1024×683 PNG) is drawn from scratch with PIL by `draw_image.py`. The entry program `main.py` (Python 3.13, standard library only) copies it to `$MAKEFUN_OUTPUT_DIR/entry.png`, deterministically — two runs write byte-identical output.

## Run

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
```
